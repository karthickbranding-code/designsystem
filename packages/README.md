# Enterprise Tech Blue Packages

The reusable system is organized by capability so products can adopt the same language without creating duplicate component systems.

- `foundations` — tokens, typography, spacing, color, elevation, accessibility
- `core` — buttons, cards, badges, avatars, inputs
- `data` — tables, metrics, filters, pagination, command palette
- `navigation` — application shell, page header, breadcrumbs, tabs
- `feedback` — alerts, status, loading, skeleton, empty and error states
- `overlays` — dialog, drawer, popover and tooltip patterns
- `forms` — inputs, search, select, date/time and file upload
- `layout` — grid, stack, responsive layout primitives
- `website` — hero, feature, CTA, FAQ and public-site patterns
- `ai` — AI chat, agent, insight and RAG patterns
- `industrial` — machine, plant, operations and system-status patterns
- `icons` — enterprise product iconography

This is one Enterprise Tech Blue system, not separate design systems.
