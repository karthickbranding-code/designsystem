# Enterprise Tech Blue — Component Catalog

Enterprise Tech Blue is organized as one reusable component system for websites, SaaS applications, AI products, analytics and industrial applications.

- Colors
- Typography
- Spacing
- Grid
- Elevation
- Accessibility

## Industrial
- Status Monitor
- Industrial status, machine, sensor and alarm patterns will graduate into reusable components as they are proven across products.

## Component maturity
A component is considered reusable when it has a stable API, documented variants/states, accessibility guidance and at least one real product use case.
