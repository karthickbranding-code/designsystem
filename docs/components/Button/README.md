# Button

## Purpose
Use Button for clear user actions.

## Variants
- Primary — main action
- Secondary — supporting action
- Ghost — low-emphasis action
- Destructive — irreversible or dangerous action

## Sizes
Small, Medium, Large.

## States
Default, hover, focus, disabled, loading.

## Accessibility
Use an action label that explains what will happen. Preserve visible focus and disabled states.

## React
```jsx
<Button variant="primary">Save changes</Button>
```
